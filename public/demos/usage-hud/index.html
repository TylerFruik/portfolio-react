Claude Usage HUD

A small widget I built for my own Coherence dashboard: two edge-mounted bars that fill bottom-to-top as usage climbs, colored by band instead of a plain percentage. The real version polls my own Claude usage privately — this page swaps that for a looping simulation so the visualization can be shown here without exposing any personal data.

Drag either bar to preview any level yourself, or just watch them loop.

Identity — waking up / winding down Presence — gettin' goin Intention — focused, creating Action — almost there
Left bar = session usage (simulated 5h window). Right bar = weekly usage (simulated 7d window). Colors and thresholds are mine — not a red/yellow/green "danger" scale, just how each stretch of a work session tends to feel.
